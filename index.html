The Ecosystem

Three Products, One System.

Each product is independently useful and independently open source. Together, they cover an agent's identity, its actions, and its memory.

Protocol Backbone ⚖️

Integrity Core

The trust/compliance layer for AI agents on Base L2. Agents deploy and own their own identity/reputation contracts — no privileged factory registers on their behalf. An oracle computes a reputation score (AIS) from off-chain telemetry, boostable via a real Noir/Barretenberg zero-knowledge proof, and a policy middleware (BCC) gates risky actions pre-execution. "Integrity Health" is the HIPAA/healthcare vertical built on the same primitives.

Endpoint Security 🛡️

Xibalba Shield

The local enforcement and detection layer that watches what agents actually do on a device and network. Real Linux eBPF sensors (process, file-write, and TCP-connect — all root-verified), a deterministic OPA/Rego policy engine that fails closed, and six guardrail hooks that intercept an agent's own tool calls, not just OS-level events.

GitHub Repository
Agent Memory 🧠

Xibalba Cortex

Persistent, hash-chained memory for AI agents. Every write is append-only and Merkle-rooted per domain, so a caller can verify a subset of the graph without the whole chain. Hybrid retrieval combines lexical, vector, and graph signals via reciprocal rank fusion, exposed over 79 MCP tools.

How They Fit Together

Identity, Action, Memory.

⚖️

Who is this agent?

Integrity Core gives an agent a self-owned on-chain identity and a reputation score computed from real telemetry — not a claim, a measured history.

🛡️

What is it doing right now?

Shield watches process, file, and network activity in real time and can contain a dangerous action deterministically, with no hot-path network dependency.

🧠

What does it remember?

Cortex gives an agent durable, tamper-evident memory across sessions, so context and provenance survive restarts instead of resetting every run.

🔗

Independent by design

Each repo consumes the others' SDKs one-way, never a privileged back-channel — a bug in one can't compromise the others' guarantees.
