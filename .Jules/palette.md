## 2026-06-03 - Accessibility Improvement: Dynamic aria-expanded for Mobile Navigation Menu
**Learning:** In the current application's mobile navigation, the `.hamburger` button's visual state is toggled using the `.active` class via JavaScript. However, this state change is not communicated to assistive technologies like screen readers, which require an `aria-expanded` attribute that dynamically updates to reflect whether the menu is open (`true`) or closed (`false`). This pattern of relying solely on visual cues (CSS classes) for interactive elements is a critical accessibility issue.
**Action:** When a toggle button manages the visibility of content (like a navigation menu), its associated `aria-expanded` attribute must be synchronously updated in the same event handler that toggles its visual state class.
